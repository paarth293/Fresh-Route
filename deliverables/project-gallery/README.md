# Project gallery — upload guide

Upload the PNG files directly. Use 01 as the cover, followed by the numbered feature screenshots. If the submission form limits image count, prioritize 01–06. Files 07–08 show evaluation and mobile access.

The cover is AI-generated conceptual artwork. Files 02–08 are actual, unaltered browser captures of the working application with synthetic sample data. Desktop captures are 1920 × 1080; the mobile capture is 390 × 844. No field-impact or safety-certification claim is implied.
